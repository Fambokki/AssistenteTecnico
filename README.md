# Assistente Tecnico per iOS

App iOS nativa che contiene l'Assistente Tecnico: diagnosi di guasti da foto e video
(informatica, reti, automazione/PLC, elettrica, elettronica, idraulica, impianti di processo),
cronologia degli interventi e confronto tra più AI gratuite.

- Ogni push su `main` compila l'IPA su GitHub Actions e la pubblica nelle **Releases**.
- Installa `AssistenteTecnico.ipa` sull'iPhone o sull'iPad con **Sideloadly** (Apple ID gratuito: va rinnovata ogni 7 giorni).
- L'archivio resta sul dispositivo. Le richieste a Gemini e OpenRouter partono dall'app.

Per aggiornare l'app: sostituisci `AssistenteTecnico/Web/index.html` e fai push.
